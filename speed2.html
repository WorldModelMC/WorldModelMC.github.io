ROCKET-2 speed follow-up

Both runs use cached FP32 inference and SAM 2 initialization. The tested change is video/JPEG writing in a background worker. It remains opt-in; these checks did not establish an overall throughput improvement. The bounded queue keeps every frame in order, waits when full, and reports write failures. Frame-difference diagnostics now use a smaller integer buffer, with the same numerical result. This is the only newly enabled optimization.

Enabled: smaller diagnostic buffer

On the HPC node, the old calculation averaged 3.91 ms and the new calculation 0.74 ms across three alternating 200-call trials on 640 × 360 RGB frames. The output matched exactly. This is a component benchmark, not a measured full-loop speedup.
